Lighthouse Keeper is an original night-harbour arcade game. Ten waves of ships drift toward the reefs in the dark; you are the keeper. Sweep the lighthouse beam with the mouse (or ← →) and hold it on a ship until its lantern turns green — its course for the harbour is set — then find the next one. Every ship docked scores +100, clearing a wave adds +50, and clearing every third wave relights a spare lamp. A ship on the rocks costs a lamp; lose all three and the light goes out. Clear all ten waves to win. Plain static files, no network, plays offline in a desktop browser.

## Run it

```sh
node serve.ts # then open http://localhost:8080 — or simply open game/index.html in a browser
```
